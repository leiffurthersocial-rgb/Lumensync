# Roadmap

Everything that is not done yet. Unfinished features are hidden in the UI until they work.

- Phase 0: scaffold (Next.js, TS strict, Tailwind, Zustand, Vitest, Playwright, CI, PWA shell)

## Next
- Phase 1 — import, grid, develop basics, histogram, history, JPEG export
- Phase 2 — color & detail tools
- Phase 3 — crop, transform, lens corrections
- Phase 4 — masks, spot removal
- Phase 5 — library management
- Phase 6 — batch export, robustness, accessibility, performance

## Out of scope (by rule)
Presets, AI features, HDR/panorama merge, tethering, any server-side processing or uploads.
